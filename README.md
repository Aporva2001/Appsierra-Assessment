# MERN Stack Project Management App

A simple Project Management App built using the **MERN stack (MongoDB, Express, React, Node.js)**. It allows users to:

- Register/login securely
- Create and manage multiple projects (up to 10)
- Create and manage tasks for each project
- Track the status of each project

---

## 🔧 Tech Stack

- **Frontend**: React, React Router, Axios, Material UI
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT

---

## 📁 Project Structure
- frontend - React Frontend
- backend - Node.js + Express backend


---

## 🚀 Getting Started

### ✅ Prerequisites

- Node.js (v16+ recommended)
- MongoDB (local or Atlas)
- npm or yarn

---

### 💻 For Running Locally

## 🖥️ Frontend Setup (React)

1. Navigate to the `frontend` folder:

   ```bash
   cd frontend
   npm install
   npm start
   ```
    The frontend will run on 
    http://localhost:3000

## 🔙 Backend - Project Management App

1. Navigate to the `backend` folder:

   ```bash
   cd backend
   npm install
   node app.js
   ```
    The backend will run on 
    http://localhost:8080
